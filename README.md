# Face Verification with Siamese Network

A facial verification project using a Siamese model built with TensorFlow/Keras.

The notebook downloads the LFW dataset, collects images through a webcam, prepares image pairs, and trains the model to determine whether two images belong to the same person.

## How to Run

Open `main_jup.ipynb` in Jupyter Notebook and run the cells in order. A webcam is required for image collection and verification testing.

## Technologies

Python · TensorFlow/Keras · OpenCV · NumPy · Matplotlib · KaggleHub
